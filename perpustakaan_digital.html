Petunjuk & Dokumentasi Proyek (README.md)

1. Deskripsi Proyek

Aplikasi Perpustakaan Digital adalah aplikasi web Single Page Application (SPA) berbasis klien yang dirancang untuk mengelola pustaka buku, peminjaman, serta hak akses autentikasi. Aplikasi ini bekerja secara mandiri tanpa memerlukan backend karena memanfaatkan kecanggihan localStorage browser.

2. Teknologi yang Digunakan

  • HTML5: Struktur antarmuka dan modal SPA.
  • CSS3 & Tailwind CSS CDN: Styling antarmuka modern, utilitas grid, & responsivitas.
  • Vanilla JavaScript (ES6+): Logika autentikasi, manajemen dom, pencarian real-time, filter, dan manipualsi data localStorage.
  • Font Awesome: Ikonografi interaktif.

3. Struktur Data & Sesi (LocalStorage)

  • perpus_users: Menyimpan array seluruh akun terdaftar (Username, Email, Password, Role).
  • perpus_books: Menyimpan array inventaris buku (ID, Judul, Penulis, Kategori, Available, BorrowedBy, Image).
  • perpus_session: Menyimpan data sesi aktif pengguna yang sedang masuk.

4. Kredensial Uji Coba Default

Administrator: admin@perpus.id / admin123
User Biasa: user@perpus.id / user123

5. Panduan Menjalankan Secara Lokal

  1. Simpan kode ini ke dalam sebuah file bernama index.html.
  2. Buka file index.html tersebut secara langsung dengan melakukan klik 2x atau seret ke dalam web browser modern (Chrome, Edge, Firefox, Safari).
  3. Aplikasi siap dijalankan tanpa perlu menginstal Node.js atau web server tambahan.
